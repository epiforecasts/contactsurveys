# Extracts meta-data and repository info from a zen4R::ZenodoRecord object

Extracts meta-data and repository info from a zen4R::ZenodoRecord object

## Usage

``` r
store_reference(records, survey_dir)
```

## Arguments

- records:

  ZenodoRecord object; the object to parse information from

- survey_dir:

  file path; location to store the meta-data file

## Value

file path; file path to the JSON file with meta-data and link(s)
